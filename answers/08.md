# Task 08 Answer

请在这里简短回答：为什么 Shell 中 `$var` 和 `"$var"` 有时会产生不同的结果？  
不加双引号对其中的参数处理方式是按空格分割开，加了引号后不会因为文件名中间有空格将一个文件名拆成两个导致报错   
比如   
```  
./my project  
```    
不加引号就会被拆成`my`,`project`   
ps：  
ai补充道，""除了空格外，还能保证内部内容的直接传递，而不识别其中的通配符，然后展开  
比如:   
```  
var="*.txt"
echo $var      # 展开成 a.txt b.txt ...
echo "$var"    # 原样输出 *.txt  
```  
这道题只需要补充上""就解决了。
